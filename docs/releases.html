Versions

<avalonia-major>.<avalonia-minor>.<release>[-suffix]. The first two segments track the Avalonia release the package is built against, because that is the compatibility question every consumer actually has; the third is the release number.

A -preview suffix makes it a NuGet prerelease: hidden from default searches and opted into on install, which is the right amount of friction for an API that may still move. 

dotnet add package AvaTerminal --prerelease
